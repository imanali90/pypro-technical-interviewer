PyPro - Voice-Enabled Technical Interviewer & Quiz Bot
A professional desktop application designed to assist with technical interview preparation, featuring automated text-to-speech feedback, an integrated knowledge base, and an interactive quiz mode.

📌 Project Overview
PyPro is an interactive, voice-enabled graphical desktop application developed to simulate a technical interview environment. It helps users practice common technical questions, test their conceptual understanding through structured quizzes, and receive immediate audio and visual feedback.

🛠️ Tech Stack & Dependencies
Programming Language: Python

GUI Framework: Tkinter (with customized scrolled text components)

Text-to-Speech Engine: pyttsx3 for real-time speech synthesis and audio feedback

Core Logic: Randomization algorithms, string processing, and conditional matching logic

✨ Key Features
Interactive Graphical User Interface: A clean desktop window built using Tkinter for smooth user interaction.

Voice-Enabled Feedback: Utilizes pyttsx3 to read questions and answers aloud, simulating a real conversational interviewer.

Built-in Knowledge Base: Stores a wide variety of technical concepts, definitions, and coding principles for study mode.

Quiz Mode: Generates random questions to test technical proficiency with immediate correct/incorrect validation.

Text Sanitization: Includes automated cleaning functions to parse formatting symbols, emojis, and code keywords cleanly before speech output.

🚀 Installation & Setup
Clone the Repository:

Bash
git clone https://github.com/imanali90/pypro-technical-interviewer.git
cd pypro-technical-interviewer
Install Dependencies:
Ensure you have Python installed, then install the text-to-speech library:

Bash
pip install pyttsx3
Run the Application:

Bash
python main.py
